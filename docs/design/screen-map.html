Карта переходов

Все связи между страницами: какая кнопка или ссылка куда ведёт и для кого. Нажмите на страницу, чтобы увидеть все её переходы. Ссылки шапки и футера вынесены отдельно ниже, иначе они связали бы каждую страницу с каждой. Админка (/admin) — отдельная зона только для команды, в карту не входит.

Страница открыта всем Нужен вход Нужна подписка Заморожена: платное только для чтения Пунктир: служебные страницы Число на странице: сколько переходов из неё Точечная линия: передача данных; число на странице — сколько потоков из неё

Есть на каждой странице

Шапка и футер одинаковые везде, меняется только набор ссылок для гостя и вошедшего.

Потоки данных

Какая страница какие данные передаёт другой. Это не кнопки, а то, что сохраняется на сервере и показывается на другой странице.

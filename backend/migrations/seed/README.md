# Seed-контент (ЧЕРНОВИК)

Черновик для показа, не проверенный контент. Рустам правит темы и навыки, Алик — материалы.

| Файл | Что внутри |
|---|---|
| `skills.yaml` | Справочник навыков и синонимов (по нему `collector` ищет навыки в вакансиях) |
| `topics-shared.yaml` | Общие темы: Git, SQL, HTTP, Linux, ООП — один раз, используются в разных профессиях |
| `qa-manual.yaml`, `python-developer.yaml`, `java-developer.yaml` | Профессия: ключевые навыки, свои темы и материалы, блоки roadmap |

Правила:

- На профессию 4–6 блоков, 15–25 тем, 15–25 ключевых навыков. Проверяет тест `go test ./internal/content`.
- `skills` у темы — какие навыки она закрывает; на этом считается % соответствия. Каждый ключевой навык должен закрываться хотя бы одной темой профессии.
- `slug` темы менять нельзя: на него завязан прогресс пользователей. Название менять можно.
- Материалы только бесплатные и официальные. После проверки уберите `review_comment` из кода загрузки или замените.

Применить: `docker compose up --build -d`, затем `docker compose exec api /app/api seed`. Повторный запуск безопасен.
